# Bootstrap Italia

Copia locale di [Bootstrap Italia](https://italia.github.io/bootstrap-italia/) **2.18.3** (licenza BSD-3-Clause, vedi `LICENSE`).

Contiene solo ciò che serve al sito: CSS, JavaScript (versione bundle, necessaria per il pulsante «Torna su» e i menu), sprite delle icone e i font Titillium Web e Roboto Mono in formato woff2. I file vengono dal pacchetto npm `bootstrap-italia`, cartella `dist/`.

Per aggiornare: scarica la nuova versione da npm, sostituisci i file e aggiorna il numero in questo file.
